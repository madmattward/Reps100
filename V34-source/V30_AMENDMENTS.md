# V30 amendments

1. Main Menu: restored visible spacing between all nine independent tiles by adding horizontal and vertical margins to each three-column row. Preserved button artwork, sounds, animations, and navigation.

## Amendment 3 — touch feedback
- Shared gradient buttons now restore their persistent selected or unselected appearance when a finger leaves the button, is released, or a gesture is cancelled.
- Touch animations are cancelled before each new transition to prevent stale visual states.
- Main menu metallic buttons clear their pressed animation when a finger drags outside.
- Preset selection remains tied to the actual saved parameters, not a transient touch.
