# Reps100 V11 source

V11 is based on the tested V10 project and incorporates the agreed V11 amendments:

- Rebuilt exercise catalogue presentation using the supplied new exercise imagery.
- Exercise detail order: title, image, Muscles Worked (Primary/Secondary), Exercise Categories, How to Perform.
- Added V11 exercise metadata/muscle mapping and new catalogue entries represented by the supplied images.
- Stronger audible roulette click feedback and more responsive exercise/routine scrolling clicks.
- Health Connect availability handling updated for built-in Android Health Connect and provider-update/install state.
- Personal Profile measurement layout rebalanced to 50/50 fields/image; BMI guide removes the selection box and uses a range line plus BMI position marker.
- Solid raised/3D treatment for buttons and exercise cards.
- Sets & Reps Manager adds +/- end controls and seven requested presets while retaining exact-100 feasibility checks.
- Create Routine adds lifted drag/reorder feedback, animated spacing, swipe-right deletion, helper text, and removes the old delete button.
- Completed Routines calorie chart uses one consistent colour per individual routine, including multiple routines on the same day.

Build baseline: compile/target SDK 36, AGP 8.9.1, Gradle 8.11.1, Java 21, versionCode 10, versionName 11.0.
